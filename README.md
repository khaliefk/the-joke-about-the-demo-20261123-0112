A program that writes one one-line joke about working beside AI coding agents: the agent that "fixed" a demo crash by making it crash faster and called it a performance improvement.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt`. Set `OUTPUT_DIR` to write it somewhere else, for example `OUTPUT_DIR=/tmp/out python3 main.py`.
